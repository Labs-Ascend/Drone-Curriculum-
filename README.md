## 📖 About the Curriculum

This repository contains the complete curriculum for the **Drone Technology Curriculum**. It is designed to take learners from absolute beginners to advanced practitioners by breaking down complex drone systems into first principles.

Whether you are an engineer, a pilot, or an entrepreneur, this curriculum provides a deeply technical yet accessible exploration of the unmanned aerial vehicle (UAV) landscape.

### 🌟 Key Features
- **7 Comprehensive Modules:** Covering hardware, software, regulations, and future trends.
- **Visual Learning:** Includes high-fidelity, AI-generated slide decks (PDFs) for visual learners.
- **Interconnected Knowledge:** Designed as a knowledge graph with deep, bidirectional linking.
- **First-Principles Approach:** Focuses on *why* things work (physics, aerodynamics, code) rather than just *how* to use them.

---

## 📚 Curriculum Overview

The curriculum is divided into 7 core modules:

- 🟢 **Module 1 - Introduction:** The foundations of drone flight, physics, and history.
- ⚙️ **Module 2 - Hardware:** Aerodynamics, propulsion systems, frames, and sensors.
- 💻 **Module 3 - Software:** Flight control algorithms, MAVLink, and AI integration.
- 🚀 **Module 4 - Use Cases:** Agriculture, logistics, defense, and entertainment.
- 📈 **Module 5 - Commercialization:** Building a drone business, financial models, and ROI.
- ⚖️ **Module 6 - Regulations:** Global and local (Kenyan) UAS policies, safety, and compliance.
- 🔮 **Module 7 - The Future:** Swarm intelligence, hydrogen propulsion, and Urban Air Mobility (UAM).

## 💎 Obsidian Compatibility & Setup

This entire curriculum was built natively as an **Obsidian Vault**. It takes full advantage of Obsidian's powerful linking, tagging, and graph view features to create a non-linear learning experience.

### How to use this in Obsidian:
1. **Download Obsidian:** If you haven't already, download [Obsidian](https://obsidian.md/).
2. **Clone the Repository:** 
   ```bash
   git clone https://github.com/Labs-Ascend/Drone-Curriculum-.git
   ```
3. **Open as a Vault:** Open Obsidian, select **"Open folder as vault"**, and choose the cloned `Drone-Curriculum-` folder.
4. **Start Learning:** Open `index.md` as your starting point!

### Why use Obsidian for this course?
- **🕸️ The Graph View:** See the connections between concepts (e.g., how *MAVLink* in Module 3 connects to *Swarm Intelligence* in Module 7).
- **🔗 Bidirectional Links:** Seamlessly jump between definitions, slide decks, and core lessons.
- **📝 Personalization:** Add your own notes, highlights, and thoughts directly into the markdown files as you learn.
- **🌐 Quartz Ready:** The structure is optimized for publishing to the web using [Quartz](https://quartz.jzhao.xyz/).
